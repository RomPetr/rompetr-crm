Прочитай `C:\Users\rp\course\content\PUBLISH-COMMAND.md` и `C:\Users\rp\course\content\PIPELINE.md`.

Аргументы команды: `$ARGUMENTS`

Выполни:

1. Разбери аргументы как часы локального времени UTC+8 (0–23), через запятую или пробел.
2. Для каждого часа создай одноразовое задание CronCreate (`recurring: false`, `durable: true`) на ближайшее наступление этого часа. Если время уже прошло — на следующий день. Если задача на это время уже есть — пропусти.
3. В промпте каждого задания опиши полный цикл: свежая новость из пяти источников → подпапка `posts/<base>/` → JSON → субагент Checker → субагент Pixly (1 PNG) → публикация `platforms.vk.content` в VK (id 243080370) и `platforms.telegram.content` с первой PNG в Telegram-канал @defidexmind через `python -I bot.py <json>` → отчёт.
4. Если аргумент `status` — покажи CronList. Если `cancel` — удали задания CP. Если `now` — выполни один цикл сразу.
5. Не задавай подтверждающих вопросов: команда считается разрешением на публикацию.

Ключевые ограничения: X только на английском; Checker обязателен; Pixly пишет только внутри `posts`; картинки в VK не загружаются (токен сообщества не поддерживает `photos.*`); Telegram публикуется только через `bot.py` (бот @mind_dex_bot, канал @defidexmind, подпись к фото до 1024 символов); Claude Code должен быть открыт, иначе session-only задания не сработают.
