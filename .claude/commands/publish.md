Прочитай `C:\Users\rp\course\content\PUBLISH-COMMAND.md` и `C:\Users\rp\course\content\PIPELINE.md`.

Аргументы команды: `$ARGUMENTS`

Выполни:

1. Разбери аргументы. Флаг `-no_post` (допустимо `--no-post`) может стоять в любом месте и означает «подготовить без публикации». Остальные токены — часы локального времени UTC+8 (0–23), через запятую или пробел, либо служебная команда `now` / `status` / `cancel`. Если после удаления флага не осталось ни часов, ни команды — считай это как `now`.
2. Для каждого часа создай одноразовое задание CronCreate (`recurring: false`, `durable: true`) на ближайшее наступление этого часа. Если время уже прошло — на следующий день. Если задача на это время уже есть — пропусти. Если был флаг `-no_post`, добавь его в промпт задания.
3. В промпте каждого задания опиши полный цикл: свежая новость из пяти источников → подпапка `posts/<base>/` → JSON → субагент Checker → субагент Pixly (1 PNG) → MD-копия через `python -I scripts/json_to_md.py <json>` → далее по режиму:
   - **без `-no_post`**: публикация `platforms.vk.content` в VK (id 243080370) и `platforms.telegram.content` с первой PNG в Telegram-канал @defidexmind через `python -I bot.py <json>` → отчёт;
   - **с `-no_post`**: остановиться после MD и PNG, ничего не публиковать, не добавлять строку в `PUBLICATIONS.md`, в отчёте указать пути к JSON, MD и PNG.
4. Если аргумент `status` — покажи CronList. Если `cancel` — удали задания CP. Если `now` — выполни один цикл сразу (с учётом `-no_post`, если он указан).
5. Без `-no_post` команда считается разрешением на публикацию. С `-no_post` публикации нет: только файлы в папке поста.

MD-файл создаётся рядом с JSON, с тем же именем: `<base>.md`. В нём тексты площадок с настоящими переносами строк, без экранированных `\n` и без JSON-обёртки — удобно копировать вручную.

Ключевые ограничения: X только на английском; Checker обязателен; Pixly пишет только внутри `posts`; картинки в VK не загружаются (токен сообщества не поддерживает `photos.*`); Telegram публикуется только через `bot.py` (бот @mind_dex_bot, канал @defidexmind, подпись к фото до 1024 символов); Claude Code должен быть открыт, иначе session-only задания не сработают.
