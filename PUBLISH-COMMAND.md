# Быстрая команда публикации «publish»

Эта инструкция позволяет запускать контент-конвейер одной строкой, без дополнительных объяснений.

## Формат команды

```text
publish 0, 2, 4, 6
```

или

```text
/publish 0, 2, 4, 6
```

Допустимы также `publish 2, 4, 6, 8` и любые другие часы.

Флаг `-no_post` готовит материалы без публикации:

```text
publish -no_post
publish now -no_post
publish 2, 4 -no_post
```

Если после флага не указаны ни часы, ни `now`, команда выполняется сразу, как `publish now -no_post`.

## Как читать команду

- Числа — часы по локальному времени **UTC+8 (Иркутск)**.
- Часы можно разделять запятой или пробелом; диапазон 0–23.
- Каждый час = одна новость = один пост в VK.
- Если указанное время сегодня уже прошло, запуск переносится на следующий день.
- Если на это время уже стоит задача, второй раз она не создаётся.
- Если время наступило «прямо сейчас» (в пределах 2 минут), запуск выполняется сразу.
- Порядок часов сохраняется; каждый запуск независим.
- Флаг `-no_post` можно ставить в любом месте. Он означает: новость, JSON, Checker, Pixly и MD создаются, но VK и Telegram не публикуются.

Пример: сейчас 22:32 10 ноября. Команда `publish 0, 2, 4, 6` создаст четыре запуска: 00:00, 02:00, 04:00 и 06:00 11 ноября.

## Что происходит на каждом запуске

1. CP ищет свежую англоязычную новость за сегодня/вчера только из The Block, The Defiant, Blockworks, CoinDesk, Decrypt.
2. Проверяет папку `posts`, чтобы не повторять темы и источники предыдущих постов.
3. Создаёт подпапку `posts/YYYY-MM-DD-HHMMSS-crypto-ai-social-content/` и JSON внутри неё.
4. Запускает субагента **Checker**: проверка русского перевода, орфографии, грамматики, пунктуации, кальки, языка X и лимитов. Checker сам правит JSON.
5. Запускает субагента **Pixly**: одну PNG-иллюстрацию в ту же подпапку.
6. Создаёт MD-копию рядом с JSON: `python -I scripts/json_to_md.py <json>`. Тексты площадок с настоящими переносами строк, без `\n` и JSON-обёртки — удобно копировать вручную.
7. Если указан `-no_post` — останавливается здесь: ничего не публикует и не пишет в `PUBLICATIONS.md`.
8. Без `-no_post` публикует `platforms.vk.content` в сообщество «Разум DEX» (id 243080370) и `platforms.telegram.content` вместе с первой PNG в Telegram-канал @defidexmind через `bot.py`.
9. Отчитывается: новость, источник, ссылки на VK и Telegram, пути к JSON, MD и PNG.

Полное описание ролей и правил — в `PIPELINE.md`.

## Что важно

- Подтверждения не запрашиваются: команда считается разрешением на публикацию. С флагом `-no_post` публикации нет — только файлы.
- Claude Code должен быть открыт: задания в этой сборке session-only и не переживают закрытие приложения.
- Токен сообщества умеет `wall.post`, но не `photos.*`. Поэтому в VK уходит только текст; картинка остаётся в папке поста. В Telegram `bot.py` публикует PNG с текстом в подписи.
- Бот @mind_dex_bot должен быть администратором канала @defidexmind с правом публикации сообщений.
- X всегда на английском. Остальные площадки — на русском.
- В конце текста каждой площадки — ссылка на главную страницу источника отдельной строкой, без подписи. Полная ссылка на статью не используется. Лимиты считаются с учётом ссылки: The Block — 26 символов, The Defiant и Blockworks — 24, CoinDesk — 27, Decrypt — 21 (два переноса + URL). Точные бюджеты — в `.claude/skills/ai-news-to-social/SKILL.md`.
- Никаких seed-фраз, приватных ключей, адресов кошельков и обещаний доходности.

## Служебные команды

- `publish status` — показать запланированные запуски.
- `publish cancel` — отменить все запланированные запуски CP.
- `publish cancel 2` — отменить запуск на 02:00.
- `publish now` — выполнить один цикл немедленно.
