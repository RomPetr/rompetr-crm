## 1. Роли

### CP — Контент Завод (главный агент)

- Ищет новость в пяти источниках: The Block, The Defiant, Blockworks, CoinDesk, Decrypt.
- Выбирает одну новость по приоритетам.
- Создаёт подпапку поста и JSON по схеме скилла.
- Оркестрирует Checker и Pixly.
- Публикует текст в VK и Telegram (бот @mind_dex_bot через `bot.py`).
- Пишет отчёты.

### Checker — QA-редактор

- Файл: `.claude/agents/checker.md`
- Инструменты: `Read, Grep, Glob, Bash, Edit, Write`.
- Проверяет: структуру папок, схему JSON, русский перевод, орфографию, грамматику, пунктуацию, кальку, язык X, лимиты площадок, отсутствие секретов и обещаний прибыли.
- Правит **только JSON** проверяемого поста.
- Обязателен в каждом цикле.

### Pixly — генератор иллюстраций

- Файл: `.claude/agents/pixly.md`
- Инструменты: `Read, Grep, Glob, Bash, Write, Edit`.
- Генерирует одну PNG через `black-forest-labs/flux.2-pro` (ProxyAPI, `https://api.proxyapi.ru/v1/images/generations`); резервный режим — `gpt-image-1-mini`.
- В промптах можно изображать значок и тикер криптовалюты, о которой новость (BTC, ETH, XRP, SOL, KAVA и другие из каталога `.claude/pixly-coin-icons.json`), и отдельные цифры по теме. Запрещены длинный текст, заголовки, логотипы некриптовалютных брендов, реальные люди и обещания прибыли.
- Пишет **только** внутри `C:\Users\rp\course\content\posts\` и вложенных папок.
- Не меняет JSON и не публикует в соцсети.

## 2. Порядок работы

```text
CP: поиск новости
  │
  ├─ создать posts/<base>/ и <base>.json
  │
  ├─ Checker: проверить и исправить JSON
  │
  ├─ Pixly: создать <base>-image-1.png
  │
  ├─ CP: опубликовать platforms.vk.content в VK
  │
  ├─ CP: опубликовать platforms.telegram.content + image-1 в Telegram (bot.py)
  │
  └─ CP: отчёт
```

Почему такой порядок:

- Checker идёт до Pixly, чтобы изображения генерировались по финальному `image_prompt`.
- Pixly идёт до публикации, чтобы к моменту поста JSON и PNG уже лежали в папке.
- VK публикует только текст: групповой токен не поддерживает `photos.*`. Telegram публикует первую PNG с текстом в подписи (до 1024 символов).

## 3. Артефакты

```text
posts/
  2026-11-11-000000-crypto-ai-social-content/
    2026-11-11-000000-crypto-ai-social-content.json
    2026-11-11-000000-crypto-ai-social-content-image-1.png
```

- `<base>` = `YYYY-MM-DD-HHMMSS-crypto-ai-social-content`.
- Время в имени — локальное UTC+8, момент создания.
- JSON — единственный источник текста для публикации.
- Одна PNG — кинематографичная 3D-иллюстрация главной идеи новости.

## 4. Правила контента

- Новость только за сегодня или вчера.
- Только пять разрешённых источников.
- Не повторять темы и источники предыдущих постов.
- Приоритеты: DEX/AMM/DeFi → AI-агенты → торговые роботы и автоматизация → кошельки и безопасность → on-chain-аналитика → регулирование и инфраструктура.
- X — только английский, до 280 символов.
- Telegram 800–1024 символа включая пробелы, без хэштегов.
- Instagram 100–200 слов, 5–10 хэштегов.
- TikTok 50–120 слов, 3–5 хэштегов.
- VK 700–1500 символов, 3–7 хэштегов.
- Никаких seed-фраз, приватных ключей, API-ключей, адресов кошельков, персональных данных.
- Никаких обещаний доходности, «100x», гарантий прибыли, призывов срочно покупать.
- Риски DeFi, DEX, кошельков и автоматизации упоминаются там, где уместно.

## 5. Права и ограничения

- Checker может править только JSON проверяемого поста.
- Pixly может создавать файлы только внутри `posts` и вложенных папок.
- Ограничение Pixly реализовано инструкцией агента и проверкой пути в `C:\Users\rp\.cache\pixly_gen.py`.
- Это не OS-sandbox: при изменении скрипта или инструкции ограничение нужно сохранять осознанно.
- VK-токен сообщества: `wall.post` работает, `photos.*` — нет (`error 27`).
- Telegram: бот @mind_dex_bot должен быть администратором канала @defidexmind с правом публикации; `bot.py` отправляет `sendPhoto` с подписью до 1024 символов.
- Задания CronCreate в текущей сборке session-only: Claude Code должен быть открыт.
- The Defiant отдаёт тело статьи JS-рендером, поэтому факты сверяются с RSS-описанием и доступными перепечатками.

## 6. Обработка ошибок

- Ошибка API изображений: одна повторная попытка, затем остановка с отчётом.
- Ошибка VK: одна повторная попытка, затем отчёт; дубли не создавать.
- Ошибка Telegram: одна повторная попытка, затем отчёт; дубли не создавать.
- Нет подходящей новости: сообщить и не публиковать пустой пост.
- Checker не смог исправить JSON: остановиться и показать проблему.
- Pixly не создал PNG: не публиковать, показать ошибку.

## 7. Точки расширения

Pipeline рассчитан на добавление субагентов. Кандидаты:

- **Analyst** — проверка фактов и цифр по первичным источникам до Checker.
- **Visual QA** — проверка PNG на текст, логотипы и визуальные дефекты после Pixly.
- **Publisher** — отдельный агент для VK/Telegram/Instagram с разными токенами.
- **Scheduler** — долгоживущий (durable) планировщик вне сессии Claude Code.

Правило добавления: новый субагент получает отдельный `.claude/agents/<name>.md`, узкую зону записи и место в порядке работы. Главный CP остаётся оркестратором и единственным, кто публикует.
